We are building a mobile app using react native and typescript that targets people who are inexperienced in using modern technology like smartphones.

-   The idea is that a digital helper that lives on your screen while enabled from the app. It is an accessibility/hover button that the user can just click and a voice agent will appear to assist. Like the claude browser extension, but for general use instead. Upon voice command, the agent will be able to access and capture the contents of your screen helping with actions that you wouldn't otherwise be able to complete. 

- EXAMPLES:
    -   An old person needs information about the security and validity of a notification/message or email. 
    -   Solves confusion with the tap of a button, by explaining the specific topic/problem using voice commands
    -   Captures, analyses, informs the user
    -   Able to fill text-areas, send messages etc.

- USER EXPERIENCE
    -   User upon opening the application and configuring their account, they have the ability to turn on the *hovering agent*
    -   The agent is clickable and opens a small menu? or instantly awaits for a voice command like "Explain what's on screen" or "Access youtube" or "Is this email safe?", "Can I click this link?", "Should I enter my credit card credentials here?".
    -   Voice commands will then be transcribed into text and sent to an LLM in order to be processed to provide a solution or to perform an action
    -   If it is a solution to be provided, the agent will either talk through voice or text depending on setting configuration inside of the app
    - Ability to call the agent with constant voice checking like Siri? Also to be configured from the settings, the goal here is to include other disabilities
